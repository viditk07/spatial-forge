# Community Conduct

Be respectful, constructive, and precise when discussing SpatialForge. Harassment, discriminatory
language, threats, deliberate disclosure of private data, and publication of uncoordinated security
exploits are not acceptable.

Keep reports focused on reproducible technical behavior. Remove photographs, models, GPS metadata,
credentials, and personal paths before sharing logs or screenshots. Maintainers may edit, hide, or
close content that violates these expectations.

Report security concerns privately as described in [SECURITY.md](SECURITY.md). Report other conduct
concerns through GitHub's repository moderation tools.
