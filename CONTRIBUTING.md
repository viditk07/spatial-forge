# Contributing

SpatialForge is currently source-visible pre-release software rather than an open-source project.
External code contributions are not accepted until contribution and licensing terms are published.

Bug reports that do not contain sensitive user data are welcome. Security issues must follow
[SECURITY.md](SECURITY.md) and be reported privately. Do not attach real photographs, models,
diagnostic archives, GPS data, credentials, or full local paths.

Maintainer changes must follow [AGENTS.md](AGENTS.md): preserve local-only operation, add tests and
documentation for behavior changes, run the relevant validation commands, and do not claim
unexecuted validation.
