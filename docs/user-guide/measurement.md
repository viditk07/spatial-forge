# Scale and Measurement

Photogrammetry initially reconstructs an arbitrary coordinate scale. In Model Review,
select two distinct surface points, enter their known real distance, choose millimetres,
centimetres, metres, inches, or feet, and apply scale. SpatialForge stores the two points,
the reconstructed distance, the real distance, and the calculated scale factor.

Choose a long, rigid reference that is clearly visible at both ends. Longer references
usually reduce click-placement error. Later point-to-point measurements use the stored
scale and are displayed with an approximation symbol. They are useful for planning and
review, but are not survey-grade and should not replace verified site measurements.
