# Roadmap

- Phase 0 — Feasibility: monorepo, architecture, tooling, hardware probe, mocked engine.
- Phase 1 — CLI pipeline: persistence, imports, quality analysis, jobs, COLMAP adapter.
- Phase 2 — Desktop MVP: dashboard, wizard, review, processing and error UX.
- Phase 3 — Viewer/export: layers, crop, scale, measurement, GLB/OBJ/PLY.
- Phase 4 — Reliability: recovery, cancellation, retry, safeguards and diagnostics.
- Phase 5 — Packaging: backend bundle, Windows installer, clean-machine verification.
- Phase 6 — Android capture app: deferred until the Windows MVP is stable.
- Phase 7 — Advanced room intelligence: post-MVP research.
- Phase 8 — Phone-only reconstruction: post-MVP R&D.
